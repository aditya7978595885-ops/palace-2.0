# Replaceable Audio (`public/assets/audio/`)

Place an optional romantic instrumental track here:
- `royal-waltz.mp3` (or `.ogg` / `.wav`)

Set `"backgroundMusic": "/assets/audio/royal-waltz.mp3"` in `public/assets/manifest.json` to play your custom music file.

If no audio file is present, **The Royal Regency** plays its built-in generative Web Audio API classical harp & strings romantic waltz completely offline!
