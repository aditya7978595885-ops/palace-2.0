# Replaceable Textures (`public/assets/textures/`)

Place optional tileable PBR/diffuse textures here:
- `marble-floor.jpg` — Replaces the procedural veined royal marble floor
- `wallpaper.jpg` — Replaces the procedural damask wall panels
- `velvet-curtain.jpg` — Replaces ballroom velvet drapes
- `rose-petal.png` — Replaces falling petal sprite texture
- `garden-path.jpg` — Replaces limestone garden walkways

Set paths in `public/assets/manifest.json` or upload textures live inside **Customization Panel -> Visuals & Assets**. Missing textures automatically fall back to rich procedural Canvas textures.
