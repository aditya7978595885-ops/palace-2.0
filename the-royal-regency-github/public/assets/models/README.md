# Replaceable 3D Models (`public/assets/models/`)

Place optional `.glb` or `.gltf` 3D models here:
- `crown.glb` — Replaces the procedural 3D Royal Crown in Chapter 5's Try-On Mirror
- `chandelier.glb` — Optional custom chandelier model
- `fountain.glb` — Optional custom garden fountain model
- `gazebo.glb` — Optional custom garden gazebo model

Set paths in `public/assets/manifest.json`, or upload a `.glb` crown directly inside the Customization Dashboard. If no external model is present, the app renders bespoke procedural Three.js sculptures.
